# career-compass
Career Compass
A Python career exploration program that guides users through career paths and validates user input.

Career Compass helps users explore potential career paths through an interactive questionnaire.

Features
Collects user information
Validates age input
Prevents crashes from invalid responses
Allows career selection
Provides technology career guidance
Technologies Used
Python
